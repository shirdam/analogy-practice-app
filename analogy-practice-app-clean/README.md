# תרגול אנלוגיות פסיכומטרי

אפליקציית ווב אינטראקטיבית לתרגול שאלות אנלוגיות בפסיכומטרי עם מערכת אדפטיבית ומעקב התקדמות.

## תכונות

- **תרגול אדפטיבי**: המערכת מתאימה את רמת הקושי בהתאם לביצועים
- **מעקב התקדמות**: ניתוח מפורט של הביצועים לאורך זמן
- **מגבלת זמן**: טיימר מותאם אישית לכל שאלה
- **ממשק עברי**: עיצוב מותאם לעברית עם RTL
- **אחסון מקומי**: שמירת נתונים בדפדפן ללא צורך בשרת

## דרישות מערכת

- Node.js 16.0.0 או גרסה חדשה יותר
- npm או yarn

## התקנה

1. **התקן Node.js** (אם עדיין לא מותקן):
   ```bash
   # macOS עם Homebrew
   brew install node
   
   # או הורד מ: https://nodejs.org/
   ```

2. **התקן את התלויות**:
   ```bash
   cd /Users/shirdamri/Documents/final_project_app
   npm install
   ```

3. **הפעל את האפליקציה**:
   ```bash
   npm start
   ```

4. **פתח את הדפדפן** בכתובת: `http://localhost:3000`

## איך זה עובד

### מערכת אדפטיבית
- מתחילה ברמת קושי 1
- כל 3 שאלות מעריכה את הביצועים
- מעלה קושי אם 2+ תשובות נכונות
- מורידה קושי אם 1 או פחות תשובות נכונות

### סיום תרגול
התרגול מסתיים כאשר:
- הושגו 15+ שאלות
- הושגה רמת קושי 6 עם 3+ שאלות
- עברו 20 דקות

### אחסון נתונים
כל הנתונים נשמרים ב-localStorage של הדפדפן:
- היסטוריית תרגולים
- ניתוח ביצועים
- הגדרות משתמש

## מורה וירטואלי (AI Tutor)

האפליקציה כוללת מורה וירטואלי מבוסס GPT-4o שיכול לעזור למשתמשים במהלך התרגול:

### תכונות המורה הוירטואלי:
- **עזרה בזמן אמת** - המשתמש יכול לשאול שאלות במהלך התרגול
- **הקשר לשאלה הנוכחית** - המורה יודע על איזו שאלה המשתמש עובד
- **הסברים מפורטים** - עזרה בזיהוי קשרים לוגיים וטכניקות פתרון
- **שיחה אינטראקטיבית** - דיאלוג טבעי בעברית

### הגדרת API:
1. קבל מפתח API מ-OpenAI: https://platform.openai.com/api-keys
2. צור קובץ `.env` בתיקיית הפרויקט:
   ```
   REACT_APP_OPENAI_API_KEY=your_api_key_here
   ```
3. הפעל מחדש את האפליקציה

**הערה:** ללא מפתח API, המורה הוירטואלי יעבוד במצב מוק עם תשובות מוכנות מראש.
